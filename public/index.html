Connection setup

  1. Create your account above, or have the operator run npm run user -- "User name".
  2. On the machine running the app, connect your Reddit session: npm run login -- USER_ID. A visible browser opens for manual login and verification.
  3. The session is saved privately for your user. All ranking and posting jobs then run headlessly through rendered Reddit pages.
  4. Test the connection, approve relevant communities, then submit your written post.

If Reddit requires verification or the page layout changes, the browser stops and reports the issue. No CAPTCHA bypass, vote manipulation, or multi-account automation — ever.

API endpoints

Every API request requires Authorization: Bearer YOUR_APP_API_KEY (except /api/signup). Each user has an isolated browser session, approved communities, and history.
