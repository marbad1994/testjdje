Connection setup

Linking your Reddit account is a one-time step — it needs someone with access to this server to run it, since it opens a real browser for you to log in (this app never asks for or sees your Reddit password). Contact support to get connected.

If Reddit requires verification or the page layout changes, the browser stops and reports the issue. No CAPTCHA bypass, vote manipulation, or multi-account automation — ever.

Technical details (for whoever manages this server)
  1. Create the account above, or have the operator run npm run user -- "User name".
  2. On the machine running the app, connect the Reddit session: npm run login -- USER_ID. A visible browser opens for manual login and verification.
  3. The session is saved privately for that user. All ranking and posting jobs then run headlessly through rendered Reddit pages.
  4. Test the connection, approve relevant communities, then submit the written post.

API endpoints

Every API request requires Authorization: Bearer YOUR_APP_API_KEY (except /api/signup). Each user has an isolated browser session, approved communities, and history.
