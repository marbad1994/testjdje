BROWSER SESSION CONNECTION

Your account. Your browser.

Users call this app’s API. The backend runs Reddit in headless Chromium.

Connection setup

  1. The server operator creates a user with npm run user -- "User name" and gives that user their API key.
  2. On the machine running the app, connect that user’s Reddit session: npm run login -- USER_ID. A visible browser opens for manual login and verification.
  3. The session is saved privately for that user. All subsequent ranking and posting jobs run headlessly through rendered Reddit pages.
  4. Test the connection, approve relevant communities, then submit your written post.

No Reddit API keys are required. If Reddit requires verification or the page layout changes, the browser stops and reports the issue. The first version cannot automate required post flair.

API endpoints

The same backend powers this workspace and programmatic use. Every API request requires Authorization: Bearer YOUR_APP_API_KEY. Each user has an isolated browser session, approved communities, and publishing history.

POST /api/rank — rank your draft

POST /api/publish — choose and publish one post

GET /api/history — submission history

A content fingerprint prevents duplicate submissions. Uncertain submission outcomes require checking Reddit; the app never retries them automatically.
